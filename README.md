# Toquinho 80 anos e Toquinho 360 · v4.2

Apresentação contínua da proposta da SevenX para a Level Up e a equipe de Toquinho. A nova estrutura usa rolagem nativa e traz o conteúdo completo em sequência.

Abra index.html diretamente no navegador. Para servir por HTTP local, execute npm start com Node.js 18 ou posterior. O endereço padrão é http://127.0.0.1:4173. Não há etapa de build.

index.html contém a copy e a ordem das cenas. styles.css contém composição, tipografia, responsividade e transições. script.js controla a formação da marca SevenX por partículas e o movimento de profundidade. O modo de movimento reduzido e a abertura sem JavaScript mantêm a leitura completa.

Para GitHub Pages, envie o conteúdo do ZIP para a raiz do repositório, incluindo index.html, assets e .nojekyll. Ative Pages para a branch e a pasta raiz. A página contém noindex, nofollow.
